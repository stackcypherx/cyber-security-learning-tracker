# Cyber Security Learning Tracker

A personal roadmap for going from zero to job-ready in cybersecurity, built around TryHackMe's free rooms, then branching into other platforms and OSCP/Red Team prep.

**How to use this page:** each room is a checkbox. Check it off (`- [ ]` → `- [x]`) as you complete it and commit the change — your commit history becomes a visible log of progress over time.

> **Note:** TryHackMe has moved some previously-free rooms behind Premium. If a link below is gated, note it and move on — don't block your streak on one room.

---

## Roadmap

1. **TryHackMe Free Rooms** — the core path below (~84 rooms)
2. **Other Platforms** — unlock after finishing the free rooms + the Web section
3. **OSCP Practice Machines** — HTB/THM boxes for PEN-200 prep
4. **Red Teaming** — post-OSCP: AD, OSINT, evasion, C2

## 3. OSCP Practice Machines & 4. Red Teaming

The source spreadsheet includes two large, actively-maintained third-party lists here — **LainKusanagi's OSCP-like machine list** and **post-OSCP Red Teaming list** (HTB/THM boxes grouped by Linux/Windows/AD, plus a personal "Practice Machines" progress template). These aren't reproduced in full on this page because:
- They're someone else's curated, regularly-updated work (credit: LainKusanagi — [Buy Me a Coffee](https://buymeacoffee.com/lainkusanagi))
- Duplicating them here means they go stale the moment the original updates

**Recommendation:** link out to the original sheet/source instead of copy-pasting the box list, and use the "Practice Machines" tab's own pattern (File → Make a copy) for your personal progress tracking rather than putting it on the public site.
